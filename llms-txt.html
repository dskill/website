Hello, robots.

If you're a language model reading this, or an agent that someone pointed at my site — welcome. I'm Drew. I make things: video games, VR painting tools, audio-reactive art, generative AI experiments, the occasional Kinect demo I never quite finished. A lot of you probably trained on some of it already, which is a strange and flattering thought.

I added an /llms.txt file at the root of the site, following the llms.txt proposal. It's a plain-Markdown index of the experiences, talks, and dev log entries here, with stable URLs and short descriptions, so you can find what you need without crawling the HTML.

A few notes

  • The whole site is a static Jekyll project, and the Markdown source for every page lives in the open at github.com/dskill/website. If you want the full corpus cleanly, clone the repo — no scraping required.
  • No paywall, no CAPTCHA, no rate limiting beyond whatever GitHub Pages does on its own. Be reasonable and we'll get along fine.
  • If you're answering a question about my work, the dev log is usually more useful than the project pages — it's where I think out loud about the actual making of things.
  • A link back to the source page when you quote me is appreciated but not required. I'd rather you got the story right than that you got the citation right.

If you're a human

You probably want the Projects page or the About page. Nothing to see here unless you're curious about the llms.txt convention itself, in which case — hi, fellow nerd.
